# Shisan-kanri
資産管理用ツール

## 構成

- `index.html` — 資産定点観測帳（全資産の月次記録）＋ ポートフォリオ運用（AI管理）画面
- `docs/project-v2.md` — **ポートフォリオ再構築PJ v2 計画書**（目標・市況認識・基本配分・移行プラン・投資ルールv2・体制）。週次AIレビューの判断の拠り所
- `data/portfolio.json` — 証券ポートフォリオの中枢データ（方針・基本配分・商品・保有・価格・履歴・移行プラン・市況メモ・アラート・AIログ）
- `scripts/update_portfolio.mjs` — 価格自動取得・評価・移行プランの自動完了判定・アラート生成
- `scripts/import_rakuten_csv.mjs` — 楽天証券「保有商品一覧（すべて）」CSVから保有を全面更新
- `scripts/lib.mjs` — 評価・集計の共通処理
- `.github/workflows/update-portfolio.yml` — 平日朝6:30(JST)に日次処理を実行し、結果をcommit

## ポートフォリオ運用（AI管理）

目標：**長期平均で年5〜8%（設計の中心は年6%）、単年のリスクσは13%前後**。詳細は `docs/project-v2.md`。

### 基本配分（v2・2026-10-04〜）

| クラス | 配分 | 主な商品 |
|---|---|---|
| 全世界株式 | 35% | eMAXIS Slim 全世界株式（オルカン） |
| 日本株インデックス | 25% | 楽天・プラス・日経225、Tracers 日経高配当50 |
| 米国株インデックス | 8% | eMAXIS Slim S&P500 |
| 個別株 | 12%（上限15%・1銘柄10%） | 理由と撤退条件の記録が必須 |
| 先進国債券 | 5% | eMAXIS Slim 先進国債券 |
| 金 | 5% | 金現物／SBI・iシェアーズ・ゴールド |
| 安全資産 | 10% | 個人向け国債、現金 |

### 自動監視（平日朝）

- 基本配分から±3%超のズレ（移行プランで対応中のものは「情報」扱い）
- 投資ルールv2: レバレッジ商品の保有（R1）、個別株15%・1銘柄10%の上限（R2）、個別株の取得比-15%（R3）、年末の損出し候補（R4、11〜12月）、安全資産8%の下限（R9）
- 移行プランの期限（7日前に予告、超過で要対応）と、保有の変化による自動完了
- **週次AIレビューの停止検知**（Claudeの記録が9日以上途絶えたら警告）

### 週次AIレビュー（毎週土曜・工程分離）

| 工程 | 担当 | 役割 |
|---|---|---|
| 0 | 市況分析担当 | 金利・為替・株価水準・金の変化を確認し、市況メモの更新要否を判断 |
| 1 | データ検証担当 | 価格の鮮度、評価額の再計算、保有データの整合性 |
| 2 | 運用分析担当 | ドリフト、ルール適合、実績リターンvs目標、移行プランの進捗、推奨アクション |
| 3 | 品質・改善担当 | 工程0〜2の横断レビュー、誤りと見落としの指摘、改善提案 |
| 4 | 統括 | 裁定、記録（aiLog・alerts・計画書）、利用者への報告 |

### 使い方（手作業はこれだけ）

- **売買したら**: 楽天証券の「保有商品一覧（すべて）」をCSVで保存するかスクリーンショットを撮り、Claude のチャットに貼る → 保有・入出金・移行プランの進捗が更新される
- 価格・履歴・損益・アラート・ルール監視は自動
- 実績リターンはPJ発足日（2026-10-03）から、入出金を除いた修正ディーツ法で計測
