## 1. 目標と、その正直な意味

**長期の複利で年5〜6%を、単年の下振れを抑えて狙う。**

利用者の希望は「年5〜8%を固く」。これに対する結論は次のとおり。

- **毎年確実に5%以上を出す組み合わせは存在しない。** ほぼ無リスクで得られるのは個人向け国債の約2%（変動10年2.05%、固定5年2.39%）と、満期まで持つ10年国債の約3%まで。
- **年8%は、大きな値動きを受け入れない限り届かない。** 現在の割高な株価と円安を前提にすると、株式90%の現状でも複利の中心は約6.4%。
- このPJで変えられるのは「どれだけ稼ぐか」より**「悪い年にどれだけ負けるか」**。同程度のリターンを、より小さな下振れで得る構成に組み替える。

**残す個別株を選ぶ基準**（計画側から「この銘柄を残せ」とは指定しない）
1. その会社が何で稼いでいるか説明できる（原典ルールB）
2. 撤退条件（「〇〇になったら売る」）を書ける
3. 個別株の合計で8%（上限10%）以内（三菱UFJ 1銘柄で約9.2%（10/23）。三菱UFJだけが約+9%上がるか、ほかの資産が約8%下がると10%に届く。資産の増加で2027年4月に約8%）

### 節税について（2026-10-05 確認済み）

楽天証券の「今年の特定口座損益」と実現損益CSV（国内株式・投資信託・米国株）で確認した結果は次のとおり。

| 特定口座・2026年 | 金額 |
|---|---|
| 国内株の実現損益（14件） | -¥31,929（利益 +¥151,295、損失 -¥183,224） |
| 米国株の実現損益（スペースX） | +¥22,945 |
| 投資信託の売却 | なし（売却はすべてNISA内） |
| **譲渡損益の合計** | **-¥8,984** |
| 配当・分配金（税引前） | +¥2,614（源泉税 ¥509） |
| **通算後の課税対象額** | **-¥6,370**（税金0円、還付予定 ¥509） |

- **損出しをしても、今年の税金は戻らない。** すでに通算後がマイナスで、相殺できる利益がない。戻るのは、配当にかかった源泉税 ¥509 だけ（特定口座内の通算で自動で処理される）
- 損失は確定申告をすれば**3年間繰り越せる**。ただし繰越が役に立つのは、将来 特定口座に利益（売却益・配当）が出たときだけ。今後の買付は主にNISA内で行う計画のため、効果は限定的。申告しないと繰り越せない
- NISA口座の実現損益（国内株 +¥68,740、投信 +¥93,205、米国株 +¥2,661、合計 +¥164,606）は税金に影響しない。売っても今年の年間枠は戻らない（生涯枠は翌年に簿価分戻る）
- 米国株の配当で引かれた外国税は通算では戻らない。金の損失は株式と通算できない
- **結論：** 含み損のある銘柄を「税のために」売る理由はない。売る・残すは投資判断（R1・R2・R3）で決める

### 2026-10-05 利用者の決定と、NISA枠の確認

- 基本配分は**案B（固め）**に決定。複利の中心5.4%、リスクσ11.0%、2008年型の急落-30%
- NISA枠を確認したところ、成長投資枠は2026年分をほぼ使い切っていた（残り¥2,362）。年間枠は売っても戻らないため、上半期の売買で消化していた。この前提を欠いたまま「成長枠でオルカンを買う」計画を立てていたので、購入ルートをつみたて枠（今年）と新しい成長枠（来年1月）に組み替えた

### 2026-10-04 独立レビューによる計画の訂正

計画の初版を別の担当（品質・改善担当）に検証させたところ、計算自体は再現できたが、前提と説明に次の問題が見つかった。いずれも訂正済み。

- 期待リターンを単純平均（算術）で示し「中心6%」としていたが、複利で見ると約5.2%だった。前提を複利に統一し、株式を7%→6%に下げた
- 「再構築でリターンが上がりリスクが下がる」と説明していたが、統一した前提では現状の方が複利の中心は高い（株式90%のため）。再構築の効果は下振れの縮小であると訂正した
- 節税額を約34,000円と断定していたが、今年の特定口座に利益がなければ当年の還付はない。「最大」に改め、確認を売却前に置いた
- その後（同日）、楽天証券の実現損益CSVで今年の特定口座の通算後が -¥6,370（相殺できる利益なし）と確定し、損出しによる当年の還付は見込めないことが分かった。「損出しで還付」を前提にしていた移行プランの年内損出しの手順は見送りに変更した
- 残す個別株の既定案（三菱UFJとイートン）は基準が一貫していなかった。基準だけを示し、選ぶのは利用者とした
- 個別株の上限を原典の30%から15%に一方的に下げていた。利用者の判断事項とした
- オルカン購入の自動完了判定が、NISAつみたての積立分を含めてしまう不具合を修正した
