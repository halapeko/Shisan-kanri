## 1. 目標と、その正直な意味

**長期の複利で年5〜6%を、単年の下振れを抑えて狙う。**

利用者の希望は「年5〜8%を固く」。これに対する結論は次のとおり。

- **毎年確実に5%以上を出す組み合わせは存在しない。** ほぼ無リスクで得られるのは個人向け国債の約2%（変動10年1.95%、固定5年2.24%）と、満期まで持つ10年国債の約3%まで。
- **年8%は、大きな値動きを受け入れない限り届かない。** 現在の割高な株価と円安を前提にすると、株式90%の現状でも複利の中心は約6.4%。
- このPJで変えられるのは「どれだけ稼ぐか」より**「悪い年にどれだけ負けるか」**。同程度のリターンを、より小さな下振れで得る構成に組み替える。

## 5. 利用者の判断事項

| # | 判断 | 選択肢 | 推奨 |
|---|---|---|---|
| d1 | 基本配分 | 案A／案B | 案B |
| d2 | 個別株の上限 | 原典の30%のまま／15%に引き下げ（あわせて1銘柄8%以内） | 15%。個別株は指数と同程度の期待リターンに対し、個別要因の値動きが加わるだけで、「固さ」と相性が悪い。ただし原典ルールの変更なので利用者が決める |
| d3 | 残す個別株 | 下の基準で利用者が選ぶ | — |

**残す個別株を選ぶ基準**（計画側から「この銘柄を残せ」とは指定しない）
1. その会社が何で稼いでいるか説明できる（原典ルールB）
2. 撤退条件（「〇〇になったら売る」）を書ける
3. 1銘柄で総資産の8%以内（三菱UFJは現在9.6%。残すなら、かぶミニで一部売却を検討）
4. 同じテーマを重ねない（イートンとVRTはどちらもデータセンター向け電力設備。三菱UFJは高配当50・日経225と銀行株が重なる）

**売却判断と節税判断は切り離せる。** 日本には米国のウォッシュセール規制がないため、残したい銘柄でも「売って翌営業日以降に買い戻す」ことで、保有を変えずに損失だけ確定できる（国内株は特定口座で売り→買いの順。投信は同日だと同じ基準価額になるため翌営業日以降）。

### Phase 2（10月〜12月）移行

- オルカンは**6か月に分けて**購入（10月から3月まで、毎月約18.5万円、合計約111万円）。為替は年単位で動くため、3〜4か月の分割では円高リスクはほとんど減らない。6か月分割は「一度に高値で買う」ことを避けるための最低限の措置
- 利付国債（新窓販10年）を約44万円（11〜12月）
- 個人向け国債を約33万円（11〜12月募集）。発行後1年は換金できないので、すぐ使うお金は入れない
- **年内の損出し**（R4）: 国内株は12/28約定まで、米国株・海外資産の投信は12月中旬までが目安（楽天の年末受渡日一覧で確定する）

売却代金のうち、まだ買っていない分は楽天・マネーファンド等で待機させる（ダッシュボードでは「現金・待機資金」として配分判定から除外）。

### Phase 3（2027年1〜3月）点検と申告

- 1月: 2027年のNISA成長枠でオルカンを購入（4回目）
- 1月: 半期点検。前提、基本配分、**積立の配分**を見直す（月10万円をすべてオルカンに積み立て続けると、2027年中に全世界株が目標を大きく超える）
- 3/15まで: 損失が今年の利益で通算しきれなければ**確定申告で繰越**（申告しないと翌年に繰り越せない）

### 節税額について

特定口座の含み損をすべて確定すると約 -¥178,000（金を除く）。今年の特定口座に同額以上の実現益（配当を含む）があれば、**最大 約¥36,000** の税金が戻る。実際の額は残す銘柄の選び方で変わる。実現益が少なければ当年の還付は減り、残りは確定申告で3年繰り越せる。米国株の配当で引かれた外国税はこの通算では戻らない。金の損失は株式と通算できない。

**2026-10-05 の確認結果（楽天証券の実現損益CSV・国内株式）:** 特定口座の今年の実現損益は**差引 -¥31,929**（利益 ¥151,295、損失 -¥183,224、14件）。国内株では相殺できる利益がすでに不足している。したがって、損出しで当年の税金が戻るかどうかは、**特定口座の投資信託・米国株の売却益と、配当・分配金が合計で ¥31,929 を超えるか**で決まる（これらは未確認）。確認前の還付額は「最大 約¥28,500」（追加で確定できる損失 ¥140,478 の20.315%）を上限の目安とし、確認できるまでは**還付を前提に売却しない**。残したい銘柄の損出しは、還付がなくても確定申告で損失を3年繰り越せば将来の利益と相殺できるため無駄にはならない（ただし申告が必要）。NISA口座の実現損益（+¥68,740）は税金に影響しない。

## 8. 投資ルール v2（今回の損失からの学び）

今回の-10%超の損失6件には共通点がある。**1銘柄が大きすぎた**、**話題・急騰の後に買った**（金は1月の最高値圏で取得）、**撤退条件を決めていなかった**（-20%超まで放置）、**ルール違反の商品を持った**（レバ）。これをルールに変える。

| # | ルール | 自動監視 |
|---|---|---|
| R1 | レバレッジ・信用取引・ブルベア型は持たない（原典ルールB） | ○ |
| R2 | 個別株は合計30%以内（原典）。15%と1銘柄8%への引き下げは利用者の判断待ち | ○ |
| R3 | 個別株は買う前に「買う理由」と「撤退条件」を記録する。取得価格から-15%で必ず見直し、理由が崩れていたら売る | ○ |
| R4 | 特定口座の含み損は、その年の特定口座に実現益（配当を含む）がある場合に年内の損出しを検討する。残したい銘柄は翌営業日以降に買い戻せる（R1違反の商品は買い戻さない）。通算しきれない損失は確定申告で繰り越す | ○（11〜12月） |
| R5 | まとまった新規購入は6か月以上に分ける。急騰後の一括購入はしない | — |
| R6 | 新規資金・積立は基本配分に足りないクラスへ入れる。積立の配分は1月・7月に見直す | ○（ズレ） |
| R7 | NISA内の含み損は損出しの対象外（税の効果がない）。売るかどうかは税ではなく投資判断で決める（売ると年間枠は戻らず、生涯枠は翌年に簿価分戻る） | — |
| R8 | 基本配分から±3%超でリバランス。原則は積立配分で調整し、売却は最小限。1月・7月に定期点検 | ○ |
| R9 | 安全資産（国債・現金）を8%以上、そのうちすぐ動かせる現金等を3%以上保つ | ○ |
| R10 | 金の売却損は株式と損益通算できない。金は損切り目的で売らない | — |

## 11. 振り返り記録

### 2026-10-04 独立レビューによる計画の訂正

計画の初版を別の担当（品質・改善担当）に検証させたところ、計算自体は再現できたが、前提と説明に次の問題が見つかった。いずれも訂正済み。

- 期待リターンを単純平均（算術）で示し「中心6%」としていたが、複利で見ると約5.2%だった。前提を複利に統一し、株式を7%→6%に下げた
- 「再構築でリターンが上がりリスクが下がる」と説明していたが、統一した前提では現状の方が複利の中心は高い（株式90%のため）。再構築の効果は下振れの縮小であると訂正した
- 節税額を約34,000円と断定していたが、今年の特定口座に利益がなければ当年の還付はない。「最大」に改め、確認を売却前に置いた
- 残す個別株の既定案（三菱UFJとイートン）は基準が一貫していなかった。基準だけを示し、選ぶのは利用者とした
- 個別株の上限を原典の30%から15%に一方的に下げていた。利用者の判断事項とした
- オルカン購入の自動完了判定が、NISAつみたての積立分を含めてしまう不具合を修正した
- 積立先変更の締切（前月12日）、年末の受渡期限の商品別の違い、個人向け国債の換金制限を追記した

### 2026-09-21 推奨の事後検証

9/21に「SBI日本株4.3ブル、VRT、三菱電機、村田製作所、オリックスを売却しオルカンへ」と推奨した。実行されなかった結果、10/3時点では**保有継続の方が約¥10,000良かった**（4.3ブルが日経平均の反発で+¥28,053、オリックスは-¥20,050）。2週間の結果は判断の良し悪しを示さない。4.3ブルの売却理由（原典ルール違反、ボラティリティ減価、償還期限）は変わっておらず、損失が縮んだ今は出口として条件が良い。

### 2026-07〜10 週次AIレビューの停止

7/15に登録した週次レビューのRoutineが消失しており、約11週間一度も実行されていなかった。価格の自動更新は毎日正常だったため気づけなかった。対策として、日次処理に「Claudeのレビュー記録が9日以上途絶えたら警告」を追加した。
