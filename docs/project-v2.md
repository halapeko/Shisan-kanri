## 1. 目標

**長期平均で年5〜8%（設計の中心は年6%）、単年の値動き（リスクσ）は13%前後に抑える。**

「毎年確実に5〜8%」を出す組み合わせは存在しない。ほぼ無リスクで得られるのは個人向け国債の約2%（変動10年1.95%、固定5年2.24%、2026年10月）までで、それを超えるリターンは必ず値動きと引き換えになる。このPJが約束するのは次の3点。

1. 期待リターン約6%を、現状より**低い**リスクで実現する配分に組み替える
2. 単年で大きく負ける確率を下げる（-10%超の年: 現状17% → 再構築後11%）
3. 下振れした年もルールで機械的に対処し、感情で売買しない体制にする

## 5. 移行プラン

### Phase 1（10月）是正：ルール違反の解消と損出し

すべて特定口座。確定損失 -¥169,583 は、同年の特定口座の実現益と相殺でき、**約¥34,000の税金が戻る見込み**（実現損益明細で特定口座分の利益額を要確認）。

| 売却 | 評価額 | 損益 | 理由 |
|---|---|---|---|
| SBI日本株4.3ブル | ¥143,911 | -36,089 | ルールB違反。期待リターン約2%に対しσ77%。償還期限あり。日経反発で損失が縮んだ今が出口 |
| バーティブ(VRT) | ¥119,442 | -40,099 | 高ベータのAI関連。米金利5%台は高PER株に逆風 |
| オリックス | ¥287,250 | -46,450 | 1銘柄7.8%は過大 |
| 三菱電機 | ¥105,280 | -26,500 | 端株20株。日経225に含まれるため指数で保有継続できる |
| 村田製作所 | ¥42,335 | -13,010 | 端株5株。同上 |
| Sansan | ¥206,900 | -6,375 | 高金利はSaaSの評価に逆風。個別株上限内に収めるため |
| FINATEXT HD | ¥144,300 | +6,585 | 個別株上限内に収めるため（利益確定） |
| 先進国債券（特定分） | ¥217,356 | -7,645 | 比率を5%へ。損出し |

**残す個別株（既定案）:** 三菱UFJ（日銀利上げが利ざや改善に効く側）とイートン（含み益）。合計¥492,106（13.3%）。
どれを残すかは利用者が選んでよい。条件は合計¥555,888（15%）以内・1銘柄¥370,592（10%）以内・理由と撤退条件の記録の3つ。

**損出しの技術:** 日本には米国のウォッシュセール規制がないため、気に入っている銘柄は「売って同日〜翌日に買い戻す」ことで、保有を変えずに損失だけ確定できる（特定口座では**売り→買いの順**で行う）。売却判断と節税判断は切り離して考えてよい。

## 7. 投資ルール v2（今回の損失からの学び）

今回の-10%超の損失6件には共通点がある。**1銘柄が大きすぎた**（オリックス7.8%）、**話題・急騰の後に買った**（金は1月の最高値圏、AI関連、レバ）、**撤退条件を決めていなかった**（-20%超まで放置）、**ルール違反の商品を持った**（レバ）。これをルールに変える。

| # | ルール | 自動監視 |
|---|---|---|
| R1 | レバレッジ・信用取引・ブルベア型は持たない | ○ |
| R2 | 個別株は合計15%以内、1銘柄10%以内 | ○ |
| R3 | 個別株は買う前に「買う理由」と「撤退条件」を記録する。取得価格から-15%で必ず見直し、理由が崩れていたら売る | ○（-15%） |
| R4 | 特定口座の含み損は年末に損出しを検討する（買い戻し可） | ○（11〜12月） |
| R5 | まとまった新規購入は3回以上に分ける。急騰後の一括購入はしない | — |
| R6 | 新規資金・積立は基本配分に足りないクラスへ優先して入れる | ○（ドリフト） |
| R7 | NISA内の含み損は損切りしない（損益通算できず、枠も翌年まで戻らない） | — |
| R8 | 基本配分から±3%超でリバランス。原則は積立配分で調整し、売却は最小限。1月・7月に定期点検 | ○ |
| R9 | 安全資産を8%以上保つ | ○ |
| R10 | 金の売却損は株式と損益通算できない（譲渡所得・総合課税）。金は損切り目的で売らない | — |

## 10. 振り返り記録

### 2026-09-21 推奨の事後検証

9/21に「SBI日本株4.3ブル、VRT、三菱電機、村田製作所、オリックスを売却しオルカンへ」と推奨した。実行されなかった結果、10/3時点では**保有継続の方が約¥10,000良かった**（4.3ブルが日経平均の反発で+¥28,053、オリックスは-¥20,050）。2週間の結果は判断の良し悪しを示さないが、レバ商品は上昇局面ではこう動く、という実例として残す。推奨の根拠（ルールB違反、ボラティリティ減価、償還期限）は変わっておらず、損失が縮んだ現在はむしろ出口として条件が良い。

### 2026-07〜10 週次AIレビューの停止

7/15に登録した週次レビューのRoutineが消失しており、約11週間一度も実行されていなかった。価格の自動更新は毎日正常だったため気づけなかった。対策として、日次処理に「Claudeのレビュー記録が9日以上途絶えたらアラート」を追加した。
