## 2. データの矛盾・古い値

1. **NISAの生涯枠 usedLifetime（1,545,549円）がどちらの読み方でも合わない**：note は「NISA内保有の取得額合計」と書くが、保有の取得額は943,448円（差 602,101円）。一方、生涯枠は売っても翌年まで戻らないので、2026年中の使用額は今年の買付額（つみたて760,000＋成長2,397,638＝3,157,638円、推定を含む）以上になるはず。どちらとも合わない。乗り換えの判断（SBIで使える残りの生涯枠）に効くので、楽天のNISA画面（または国税庁の管理）で確認が要る。
2. **ANTの売り注文がデータに入っていない**：ANTは holdings に20株のまま、tax.pendingSales は空。注文は aiLog（11-23c）の文中にあるだけ。約定・受渡までは「売却中」で、移管の対象から外す扱いが要る。
3. **cash_bank の product の note が古い**：products[cash_bank].note は「銀行残高は未確認」のままだが、holdings 側では11/22に利用者の報告（約111万円）で確認済み。
4. **cash_bank に入っていない出入り**：未払いのカード代金20万（11/27・12/28）、ANT代金約28万（入金待ち）、12/1のカード積立。帳簿の86万は「今日の実残高−第188回の代金」で、正味の待機資金ではない。
5. **価格と為替の日付がずれる**：投信・株の priceDate は2026-11-20、金は11-22、為替は11-23（158.89円）。ANTの評価額は11/20の株価×11/23の為替。11/21〜23の自動更新は1回成功・2回失敗（aiLog）。乗り換えの判断には効かない差。
6. **nisa の日付が古い**：nisa.asOf は「10/5の楽天画面の値＋推定積立」。11/1積立分は推定。scheduledThisYear.note は「11月・12月の積立 各10万円」と書くが値は10万円（11月分は利用済に移した後の値で、文が古い）。
7. **第191回の発行月が「要確認」のまま**：換金できる時期（発行から1年）と、移管するかどうかの判断に効く。
8. **history の flow**：11/22の cash_bank の修正（-28,968円）とANTの取得は flow 0 で記録。前回の指摘（カード積立を外部入金と数えた11/2の+100,000）も未解決。乗り換え自体には効かないが、移管・入出金が増えるとPJの実績の計算がさらにずれる。
9. **金現物の口座区分**：account が "-" で、どこにあるか（楽天の金・プラチナ取引）はデータの構造からは分からない（aiLog と plan の文中にだけある）。

## 3. 計算が依存している仮定

データの外の事実（工程1で確認すべきもの）：
- A1 楽天証券の特定口座の国内株・米国株は、SBI証券の特定口座へ移管（出庫）できる。手数料・日数は未確認。外国株は別の手続きの可能性がある。
- A2 投信（eMAXIS Slim 米国株式・特定）は、移管先でも同じ投信を扱っていれば移管できる。
- A3 楽天の金現物は他社へ移管できず、売るか現物で引き出すしかない。金の売却損益は特定口座の株・投信とは通算しない（総合課税）。
- A4 個人向け国債は他社へ振替できる。発行前（第188回、12/15まで）はできない。
- A5 NISA内の保有は他社へ移せない。今年の枠を楽天で使っているので、金融機関を変えられるのは2027年分から。**2027年に楽天のNISAで1回でも買う（1月のカード積立を含む）と、2027年分は楽天から変えられない**と考えられる。手続き（勘定廃止通知書）の期間中はNISAで買えない。いずれもデータからは確認できない。
- A6 生涯枠は保有の取得額で管理され、2026年に売った分は2027年に戻る。楽天に残すNISA保有もSBIでの生涯枠に数えられる（国税庁が一元管理）。
- A7 移管しても取得額は引き継がれ、今年の特定口座の損益（-167,653）は楽天で確定する。他社分と合わせるには確定申告が要る。

計算上の仮定：
- B1 価格は今のまま（投信・株11/20、為替11/23）。国債は額面で評価。
- B2 ANTは成行で20株が売れ、代金は約280,697円（手数料0.495%、為替コスト0.25円は前回の仮定を流用）。税はかからない。
- B3 「売って移す」は特定口座の株・投信だけを今年中に売る場合。国債・金・NISAは含めない。配当・国債の利子は入れていない。
- B4 カード積立は12/1に10万円が約定し、つみたて枠の利用済に加わる（recurring.estimated）。34万の使い切りは保留（11-23cの推奨どおり取り消す場合と、買う場合の両方を示した）。
- B5 cash_bank は楽天銀行の残高で、楽天証券の口座と同じ扱いではない（乗り換えても、カード代金・国債の代金・生活費の口座としては残る）。
- B6 住信SBIネット銀行の60万円は生活防衛資金でポートフォリオの外（emergencyFund）。SBI証券と同じ系列だが、連携（SBIハイブリッド預金など）の有無はデータにない。
