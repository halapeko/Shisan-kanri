# 統括の原案（2026-11-23d、工程1・2を見る前）

利用者の質問：「楽天証券が個人情報流出したけど、SBI証券に乗り換えるのはどうか」

## 原案
1. まず事実を確かめる（いつ・何が・何件・お金や取引に被害が出る種類か、楽天証券の発表）。報道だけで動かない。
2. 乗り換えの前にできる守り：パスワード変更、二段階認証・ログイン通知の設定、楽天証券を名乗るメール・SMSのリンクを開かない、取引履歴の確認。
3. 乗り換えは「全部か、一部か、新しいお金だけか」に分けて考える。
   - NISA：今年の枠はすでに楽天で使っているので、金融機関の変更は早くても2027年分から。今あるNISAの投資信託は移せない（楽天に残る）。
   - 特定口座の株・投信、個人向け国債：移管できるが、手数料・手間・期間がかかる。
   - 待機資金（楽天銀行・マネーブリッジ）と住宅資金：証券会社の変更とは別。
4. 当面（12月の判断・つみたて枠の扱い・カード積立）は楽天のまま進め、事実が分かってから、2027年のNISAをSBIにするかを1月の点検で決める。
