## 2. 最も強い反論

**原案は「カードの引落し口座が分かった」を部分修正で済ませているが、計画の前提そのものが崩れた。配分を「65のまま」と言える状態ではない。**

1. 計画は「毎月10万円が外から入り、待機資金で残りを買う」形で組まれていた（s15「待機資金約140万円で足りる」、前回の「4月末に約408万円」）。実際は外からの入金がゼロかもしれず、正味の総資産は約338万円。計画どおりに買うと、20株売っても3月に資金が尽きる。
   - 原案の「4月末に不足」「成長枠を減らす・止める」は、時期も対策の大きさも足りない。
   - 12月の国債10万円と、5月以降のカード積立も止める対象になる。
2. 住宅資金の金額によって、この約338万円が「長期資金」か「数年以内に使うお金」かが逆転する。頭金の平均は約230万〜1,340万円（フラット35利用者の平均、二次情報）。
   - たとえば2〜3年以内に200万円以上なら、ポートフォリオの過半は短期資金になる。株65%は、短期資金に株を半分以上持たせる配分になる。
   - 原案は「住宅資金を別にして残りを65で」と言うが、残りがほとんどない場合は意味がない。
   - 別にするために株を売るなら、R8の「売却は最小限」とR2の分母の定義（住宅資金を外すと個別株が18〜31%になる）が衝突する。原案はこれに触れていない。
3. 配分の決定を1/20まで延ばすと書いているが、12/17の34万円（株）は配分の決定より前に買う。前回の「12月の買付はどの配分でも同じ」は、住宅資金がない前提での話だった。住宅資金がありうると分かった今は、成り立つか分からない。
4. 許容度の根拠（11/6・11/20に売りたくなかった）は、保有-2%程度の経験にすぎない。2008年型（約-100万〜117万円、モデル）を売らずに耐えられるかの答え（U8）は、まだない。
5. したがって「許容度の面では65のままでよい」も「65を前提に住宅資金を外す」も、言える根拠がない。言えるのは次の3つだけ。
   - ANTは20株売る（R2）。
   - 待機資金からの買付は、入金の事実が分かるまで止めるか減らす（R9）。
   - 配分は、住宅資金の時期・金額・出どころと、給料の余りが分かってから決める。

## 3. 代替案

**代替案A（推す）：先に資金の出入りを確定させ、それまで待機資金からの株の買い増しを止める**
1. ANTは20株、年内に売る。理由はR2だけで書く（18株では上限を超える）。利用者の意図とは独立の理由として書く。
2. 給料からの入金（毎月いくら、何日に）が分かるまでは、次のようにする。
   - 1〜4月の成長枠を止める。
   - 12月の固定国債10万円は止めるか延期する。
   - カード積立（月10万円）は、入金が月10万円未満なら減額を検討する。
   - 入金が分かったら、工程2の表（X≒8.7万/11.3万）で戻す額を決める。
3. 12/17のつみたて枠34万円は、**12月上旬までに住宅の時期の答えをもらって決める**。
   - 3年以内なら、見送るか減額する（年間枠は消えるが、元本は残る）。
   - 5年以上先、または住宅資金を投資資金から出さないなら、予定どおり買う。
   - 年数の線は公的基準ではなく、出典で3〜10年と幅があることを伝える。
4. 配分（65か、それより下か）は、住宅資金の時期・金額・出どころとU8が分かってから決める。1/20の期限は、答えがそろえば守る。
5. 住宅資金を分けた後のR2・R9の分母（全体か、投資に回す分だけか）を、利用者の決定事項として先に決める。

**代替案B：住宅資金を最優先にし、ポートフォリオ全体を中期の資金として作り直す**
- 購入が3年以内で、金額が正味の過半なら、株の目標を大きく下げる（例：株30〜40%）。株はNISAの中だけに置く。
- 期待リターンは5%を明確に下回る（モデル）ので、「年5%」の目標は住宅購入の後の資金に移す。
- 利用者が「5%を下回るなら投資の意味がない」と考えるなら、この案は受け入れられない。それも含めて、優先順位を選んでもらう。

**ANTについての代替（利益相反の対称性のため）**
- 三菱UFJかオリックスを売ってANTを残す道も、R2の数字の上では成り立つ（前回のD案）。
- 前回は「上限13%は三菱UFJ・オリックスを残すために決めた」ことで退けた。しかし利用者は、その2銘柄の理由を「忘れた」と答えている。退けた根拠は前回より弱い（4章）。
- それでも利用者自身が売りたいと言っているので、結論は20株で変わらないと考える。ただ、退けた根拠が弱まったことは記録に残すべき。

## 4. ルール解釈・利益相反の点検結果
