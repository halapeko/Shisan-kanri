# 統括の原案（2026-11-22に利用者へ送った推奨。工程分離を通していない）

## 利用者の状況と依頼
- 11/20の急落（日経-5%、S&P500 -3.7%）を受け、「今の下落傾向は楽観的か、計画を見直してほしい、どのポートフォリオを持つべきか、どこまでなら耐えられるか」を依頼。Anthropic株20株（IPO当選）を保有。
- 統括が「2008年型で何万円まで売らずに持てるか」「個別株をどうするか（A〜E）」「生活防衛資金はあるか」を聞いたところ、利用者は「判断基準がわからないから委ねずに推奨案を示して」と回答。生活防衛資金は「住信SBIネット銀行60万円、楽天銀行111万円、妻が個人で管理する約300万円（度外視）」。

## 推奨1：基本配分を 株65・守り35 → 株60・守り40 に下げる
- 判断基準（統括が置いた）：年5%の目標を守れる範囲で、暴落したときの損がいちばん小さい配分を選ぶ。
- モデル：65 → 期待5.35%・2008年型 -124万円、60 → 5.17%・-115万円、55 → 4.98%（目標割れ）・-105万円（2027年4月末の総資産 約412万円）。固定国債を今の2.17%にしても60は5.10%。
- 理由：5%を守れる一番低い比率／生活防衛資金が60万円で厚くはない／今回の下落で計画を見直したくなったこと自体が、65が少し攻めすぎだったサイン／何も売らず、これからの買い方を変えるだけ。
- 代わりに失うもの：期待値で年0.18pt（10年で約12万円）。
- 変更点：2027年1〜4月の成長枠のオルカンを月4万→2万円、個人向け国債（固定5年）を1月・2月に5万円ずつ追加。12月の予定は変えない。
- 60・アンソロピック売却の2027年4月末の見込み：株59.9%、期待5.11%（固定2.17%で5.05%）、2008年型 約-113万円、現金 約14.5万円（3.6%）。

## 推奨2：アンソロピックは20株すべて売る。三菱UFJとオリックスは持つ
- 判断基準（ルール3つ）：①個別株は合計13%以内（R2）②「買う理由」と「撤退条件」を書けない株は持たない（R3）③計画の資金を削らない。
- ①全部売ると個別株は20.0%→約12%で上限内。18株だけ売ると約12.8%で上限ぎりぎり、株価が戻るとまた超えるので全部。
- ②三菱UFJ・オリックスは記録があり撤退条件は未成立→持つ。アンソロピックは記録なし→売る。
- ③IPOの代金26.5万円は12〜4月の買付に使う予定の現金から出た。持ったままだと現金が約11〜13万円足りなくなる。売れば約14.5万円残る。
- 会社の評価ではなく、同じ状況のIPO株ならどの会社でも同じ結論。
- 売り方：成行で20株、11/23夜（米国市場）以降、円貨決済、代金約28万円、税金なし（今年の特定口座は-16.8万円の損失）。値上がりを待たない（売る理由はルールで、株価ではない）。
- オリックス：撤退条件に「キオクシア関連を除く純利益が2期続けて減益なら売る」を追加推奨。三菱UFJ：次の見直しは-20%（2,850円）。

## 推奨3：生活防衛資金
- 住信SBIの60万円を生活防衛資金とし、配分の外に。楽天銀行は投資の待機資金（帳簿86万円＝111万円−第188回25万円）。
- 月の生活費が20万円以内なら3か月分以上あり最低限は足りると判断。超えるなら楽天銀行の一部を回す。

## 11/22の前段の回答（市況の見方）
- 「すぐ戻る」も「戻らない」も当てる方法はない。S&P500の10%以上の下げは1950年以降約38回、20%以上は約14回（3〜4回に1回）。調整は3〜8か月、弱気相場は1〜2年以上、2000・2008年型は4〜7年で回復（二次情報）。
- 計画は戻る時期を前提にしていない。期待5.35%は暴落を含めた長期平均。売らなければ損は確定しない。
- 決め方として「2008年型で-124万円でも売らずにいられるか」を提示。
