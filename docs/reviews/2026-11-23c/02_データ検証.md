## 2. データの矛盾・古い値
1. **給料・生活費の口座が未確認（結論に最も効く）**：userProfile.salaryIntoRakutenBank は「入金先は楽天銀行と解釈、要確認」。生活費が楽天銀行から出るかどうかもデータにない。出るか出ないかで、2028年11月の住宅資金は約400万円変わる（214.6〜248.8万円か、614.6〜648.8万円か）。
2. **帳簿の作り方と給料の入金が合っているか分からない**：cash_bank は売却代金などを積み上げた額で、利用者が報告した残高（約111万円）との差は-28,968円だった（11/1の原因不明の+28,123円とほぼ相殺）。10/30にも28万円の給料が楽天銀行に入っていたなら、帳簿は給料と生活費の差額の分だけずれるはず。差が小さいので、「給料が入り、生活費とカード代金も出ている（差し引き月約2万円）」とは合うが、「生活費は出ていない（月+18万円）」とは合わない。ただし10/27のカード代金（9/1分）を帳簿でどう扱ったかが分からないため、これは推定にとどまる。
3. **年収と手取りの関係**：brain の本人年収約420万円からの手取りは、年約330万円前後（推定）。手取り28万円×12か月＝336万円とほぼ同じなので、**ボーナスはない、または28万円がボーナスをならした額**である可能性がある。この計算にはボーナスを入れていない。住民税の変わり目（毎年6月）で手取りが変わることも入れていない。
4. **生活費の家賃が10万円か8万円か**：livingCostNote は「生活費6万＋家賃10万」、brain は「家賃10万（自己負担8万）」。会社の補助2万円が給料とは別に出ているなら、楽天銀行から出る生活費は14万円かもしれない（2年間で48万円の差）。逆に、28万円に住宅手当が含まれているなら16万円のまま。
5. **生活費が月16万円で一定か**：年払いの保険・帰省・冠婚葬祭・家電の買い替えなど、毎月ではない出費は入れていない。余りが月2万円しかないので、年に24万円を超える臨時の出費があると、住宅資金は2年間で減っていく。

## 3. 計算が依存している仮定
